DOMAIN COMPLEXITY & SCOPE FORMULATION

Coastal Surveillance Challenges & Research Objectives

Why standard computer vision models fail in unstructured beach environments and how our specialized spatial detection framework resolves marine optical disturbances.

⚠️

Critical Coastal Optical Complexities

  • Extreme Scale Disparity: Due to elevated camera vantage points, beachgoers near the shoreline occupy over 120 pixels, whereas distant swimmers in breaking surf span merely 6 to 12 pixels.
  • Dynamic Water Glare & Sun Reflections: Sunlight reflecting off breaking waves and white-water surf mimics small moving objects, triggering false alarms in off-the-shelf detectors.
  • Severe Partial Submergence: Swimmers navigating breaking wave crests are intermittently submerged, leaving only heads or upper torsos visible.
  • Inanimate Visual Clutter: Orange safety cones, beach umbrellas, sunbather towels, and surfboards produce high false-positive rates in generic COCO pre-trained models.
  • Manual Surveillance Constraints: Lifeguard high-tower observation suffers from rapid visual fatigue, adverse weather blind spots, and subjective crowd density estimations.
🎯

Core Technical Objectives

  • Multi-Paradigm Benchmarking: Implement, optimize, and rigorously benchmark 5 deep learning paradigms: Detectron2 (Two-Stage R-101 FPN), RT-DETR (Vision Transformer), YOLOv8x-P2 (Small-Object Head), Faster R-CNN (Two-Stage Proposal), and RetinaNet (Dynamic Focal Loss).
  • Sub-Scale Anchor Architecture: Reconfigure Region Proposal Networks with custom 16px sub-scale anchors (`[[16], [32], [64], [128], [256]]`) to prevent tiny distant swimmer proposal dropouts.
  • Dual-Zone Spatial Classification: Discard generic single-class labeling in favor of precise spatial domain classification: Class 0: Coastal (Water Swimmer) vs. Class 1: Human on Land (Beachgoer).
  • Geometric Clutter Rejection: Institute dual post-inference filters: confidence cutoff ($\text{conf} \ge 0.40$) and bounding box aspect ratio ($H/W \ge 0.55$) to eliminate towels and surfboards.
  • Dual-Line Verification Telemetry: Annotate every evaluation scene with a clear 60px dual-line banner comparing Ground Truth with Model Prediction (`L: Count`).

DATASET AUDIT & PREPROCESSING PIPELINE

Coastal Dataset Auditing, Class Inversion Fix & Sanitization

Transforming noisy raw surveillance data into a verified 702-image, 16,022-annotation benchmark for rigorous deep vision evaluation.

DEFECT 1 RESOLVED

Semantic Class Inversion Bug

A systematic audit revealed that raw Roboflow dataset annotations inverted standard semantics: dry beach sand was indexed as 0 and open ocean water was indexed as 1.

ROBOFLOW_TO_MODEL = {0: 1, 1: 0}
# Raw 0 (Sand) -> Model Class 1: Human (Land)
# Raw 1 (Water) -> Model Class 0: Coastal (Water)

Applied across all PyTorch dataloaders, dataset YAML configs, and COCO evaluation scripts.

DEFECT 2 RESOLVED

1,874 Clutter Artifacts Purged

Human annotators in public coastal sets frequently mislabeled non-human beach equipment as people. We performed an exhaustive audit and removed 1,874 spurious boxes:

  • ❌ Orange traffic & warning cones
  • ❌ Flat sand towels & picnic blankets
  • ❌ Sun umbrellas & surfboards

Purged via automated bounding box aspect ratio rules ($H/W \ge 0.55$) and manual verification.

Detectron2: Faster R-CNN with ResNet-101 Backbone & FPN

Primary architecture chosen for coastal high-tower surveillance. Built on FAIR's modular platform, it combines a 101-layer deep residual network with lateral Feature Pyramid connections ($P_2$--$P_6$) and customized 16px sub-scale anchors.

Backbone:ResNet-101 (4 residual stages, bottleneck blocks)
Feature Neck:Feature Pyramid Network (FPN, 256 uniform channels)
Custom Anchors:[[16], [32], [64], [128], [256]] with ratios [0.5, 1.0, 2.0]
RoI Pooling:RoIAlign 7×7 continuous bilinear interpolation
Loss Formulation:$\mathcal{L} = \mathcal{L}_{\text{rpn\_cls}} + \mathcal{L}_{\text{rpn\_box}} + \mathcal{L}_{\text{roi\_cls}} + \mathcal{L}_{\text{roi\_box}}$
Training Iterations:6,000 iterations ($\approx 52$ epochs) on Dual Tesla T4 GPUs

RT-DETR: Real-Time DEtection TRansformer with Hybrid Encoder

Eliminates the Non-Maximum Suppression (NMS) heuristic bottleneck using Hungarian bipartite matching. Combines convolutional feature extraction with an efficient hybrid encoder (AIFI + CCFM) to deliver benchmark-leading global attention.

Backbone:High-performance HGNet-v2 / ResNet-50 extracting S3, S4, S5
Hybrid Encoder:AIFI (Intra-scale interaction on S5) + CCFM (Cross-scale fusion)
Query Selection:IoU-aware query selection initializing 300 target queries
Transformer Decoder:6 decoder layers with deformable cross-attention
Loss Formulation:End-to-end Bipartite Hungarian Loss (Focal Loss + GIoU + L1)

YOLOv8x-P2: Stride-4 Micro Head Architecture

Features a specialized Stride-4 ($P_2$, $160\times160$) feature pyramid upsampling level specifically designed to retain spatial pixel clusters of tiny distant swimmers that standard Stride-8 architectures drop.

Backbone:Modified CSPDarknet with C2f cross-stage bottleneck blocks
P2 Head Innovation:Dedicated Stride-4 upsampling branch (160×160 feature grid)
Head Structure:Decoupled anchor-free classification & box regression subnets
Loss Formulation:Task-Aligned Assigner (TAL) + CIoU + Distribution Focal Loss (DFL)
Speed Throughput:46.2 FPS on Tesla T4; sub-20ms real-time latency

Faster R-CNN: ResNet-50-FPN Canonical Proposal Framework

Decouples candidate region proposal generation from classification. Features a Region Proposal Network (RPN) paired with RoIAlign continuous coordinate pooling to extract disciplined proposals amidst ocean surf wash.

Backbone:ResNet-50 with lateral Feature Pyramid Network connections
Proposal Engine:RPN generating candidate object proposals ($3\times3$ sliding conv)
Pooling Method:RoIAlign continuous bilinear interpolation to uniform 7×7 feature maps
Classification Head:Two 1024-d fully connected layers feeding Softmax & Smooth L1
Proposal Precision:98.94% precision on high-confidence matched proposals

RetinaNet: ResNet-50-FPN with Dynamic Focal Loss

Formulated to conquer extreme class imbalance between vast background sea tiles and tiny human bathers. Employs dynamic Focal Loss ($\alpha=0.25, \gamma=2.0$) to suppress gradients from easy wave glint and sunlight reflections.

Backbone:ResNet-50-FPN producing multi-scale pyramids P3 to P7
Loss Formulation:$\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$
Focusing Factor:$\gamma=2.0$, down-weighting well-classified sea background by up to 1000×
Subnets:Separate classification subnet and box regression subnet across pyramids
Inference Speed:32.0 FPS sustained throughput on Tesla T4

STEP 3: DEEP ARCHITECTURE & SUB-SCALE ANCHOR DESIGN Architectural Rigor

16px Sub-Scale Anchor Generator & Stride-4 Micro-Head

Standard 32px base anchors fail to propose candidate regions for tiny 6px--12px swimmers. Customized the Region Proposal Network in Detectron2 to anchor scales `[[16], [32], [64], [128], [256]]` with aspect ratios `[0.5, 1.0, 2.0]`. Simultaneously engineered the Stride-4 ($P_2$, $160\times160$) micro-head in YOLOv8x-P2 to prevent spatial collapse of small offshore bathers.

16px Sub-Scale Anchor Generator RoIAlign 7×7 Continuous Pooling YOLOv8x-P2 Stride-4 Head Multi-Task Loss Balancing

STEP 4: 5-MODEL BENCHMARK & HARD-NEGATIVE MINING Empirical Evaluation

Multi-Paradigm Model Convergence & Marine Glint Suppression

Converged all 5 models on Dual Tesla T4 GPUs. Formulated dynamic Focal Loss ($\alpha=0.25, \gamma=2.0$) in RetinaNet to suppress breaking surf foam false alarms. Evaluated RT-DETR with Hungarian bipartite matching (94.86% mAP@0.50), Detectron2 Faster R-CNN (94.15% mAP@0.50), Faster R-CNN (98.94% precision), and YOLOv8x-P2 (46.2 FPS).
